# `public/geo/` — map geometry

## `world-countries.json`

The country outlines `src/components/geo/GeoMap.tsx` fetches at runtime. It is a
static asset rather than a module so it stays out of every JS bundle that imports
the component, and so the browser can cache it across pages.

| | |
|---|---|
| **Generated by** | `scripts/generate-geo-atlas.mjs` (one-off; not part of the build, not a dependency) |
| **Geometry source** | [world-atlas](https://github.com/topojson/world-atlas) v2 `countries-50m.json` — **ISC licence**, (c) Mike Bostock |
| **Underlying data** | [Natural Earth](https://www.naturalearthdata.com/) 1:50m Admin 0 countries — **public domain** ([terms](https://www.naturalearthdata.com/about/terms-of-use/)) |
| **Code table** | ISO 3166-1 numeric to alpha-2, cross-checked against [mledoze/countries](https://github.com/mledoze/countries) — **Unlicense** (public domain) |
| **Projection** | Equal Earth (Savric, Patterson & Jenny, 2019) — equal-area |

No part of this is a runtime or dev dependency: the TopoJSON decoding, the
projection and the simplification are all implemented in the generator.

### Regenerating

```bash
node scripts/generate-geo-atlas.mjs                 # fetches the source over HTTPS
node scripts/generate-geo-atlas.mjs --source ./countries-50m.json --out /tmp/atlas.json
```

The script prints the byte size, the ISO-code count and a sanity check, and exits
non-zero if a handful of well-known countries are missing or malformed.

### Shape

```jsonc
{
  "viewBox": "0 0 2000 974",
  "paths": { "US": "M150 35L…Z", … },   // ISO 3166-1 alpha-2 -> SVG path data
  "unclaimed": ["M…Z", …],              // land with no ISO code; background only
  "enlarged": ["SG", "MT", …],          // drawn at a minimum size, see below
  "order": "largest-first"
}
```

`paths` is ordered **largest country first**, and consumers must render in that
order: SVG paints in document order and hit-tests the topmost shape, so a small
country drawn on top of its large neighbour is what keeps Monaco, Vatican City and
Macao clickable at all.

### Three properties worth knowing before trusting the picture

**Equal Earth, not Mercator.** The map's job is "where are our people", and
Mercator answers that wrongly: it inflates area without bound towards the poles,
drawing Greenland larger than Africa, which is fourteen times its size. Equal
Earth is equal-area, so a country's share of the ink is its share of the land.

**57 countries are drawn larger than they are.** Singapore is 0.4 degrees across;
at any scale a world map is drawn its true outline is a fraction of a pixel, which
is neither visible nor clickable. Those countries are drawn as a fixed-size square
on their true position instead, and every one of them is listed in the `enlarged`
array so the distortion is stated rather than hidden. Natural Earth ships a
separate "tiny countries" point layer for the same reason. A consequence: an
enlarged square can overlap the neighbour it sits inside (Vatican City over Rome,
Macao over Hong Kong).

**Three polygons have no ISO 3166-1 code** and are in `unclaimed`: they are drawn
as plain background land so the map has no holes where land should be, and they can
never be selected or coloured. Kosovo is the one exception — ISO 3166-1 has no
entry for it either, but `XK` is the user-assigned code in general use, so it is
keyed under that.

### Why the PDF export constrains this file

`src/lib/chart-capture.ts` rasterises a chart by serialising its `<svg>` into an
isolated document, so the geometry must survive with nothing but a whitelist of
computed presentation properties. That is why the paths are plain `M`/`L`/`Z` with
flat fills applied at render time, with no gradient, pattern, `clip-path`, `mask`
or `filter` anywhere — `inlineStyles` drops any computed value starting with
`url(`, and the other three are deliberately absent from its whitelist.
